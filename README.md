# 2026 CL 경영평가 계산기 (지국팀)

지국팀 실적을 입력하면 경영평가 항목별 배점·가점과 총점을 계산하는 휴대폰용 웹앱입니다.

## 사용법
1. `index.html`을 휴대폰 브라우저로 열고 "홈 화면에 추가"를 누르면 앱처럼 쓸 수 있습니다.
2. 홈 탭에서 기초 데이터(비교 조직 수, 렌탈관리계정, 렌탈 순주문, 해약, 소유권 도래)를 먼저 입력합니다.
3. 신규·재렌탈·전략·관리·조직 탭에서 항목별 실적을 입력하면 점수가 바로 계산됩니다.
4. 분석 탭에서 카테고리별 달성률, 점수 올리기 추천, 놓친 기본점수를 확인합니다.

입력값은 해당 기기 브라우저에만 저장됩니다.

## 해석 기준
- 정·청·비 신규렌탈 성장률: 기본점수 + 가점 합계 최대 7점
- 자가관리 재렌탈 1건 → 1.5건: 계정순증은 순주문에 건당 0.5건 추가, 사전계약 유입률은 자가관리 건 ×1.5
- 직전 3개월 평균: 실적이 있는 달만 평균, 정·청·비 성장률 평균은 정수 반올림
- 인당평균계정 & 모집, 팀장임용, 감점: 본사 통보 점수 직접 입력
- 점수 올리기 추천: 6년 약정(금융리스) 기준, 상대평가 순위 변동 미반영
